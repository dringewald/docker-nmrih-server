# No More Room in Hell - Dockerimage
Dieses Image stellt einen vollfunktionsfähigen No more room in Hell-Server bereit.

## Variablen
|Variable|Wert|Beschreibung|
| ------------- |:-------------:| -----:|
|UPDATEPACKAGES|true / 1|Aktualisiert beim Starten des Images alle Pakete|
|USERPWD|Passwort|Setzt ein Nutzerpasswort für die Nutzung via SFTP|
|UPDATECHECK|true / 1|Aktualisiert beim Starten des Images den NMRIH-Server|
|VALIDATECHECK|true/ 1|Validiert beim Starten des Images die NMRIH-Dateien|
|SETPERMS|true / 1|Setzt beim Starten des Images die korrekten Berechtigungen|
